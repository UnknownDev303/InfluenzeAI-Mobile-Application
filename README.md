# 🚀 Lily — AI Marketing Agent

### 💡 Overview

**Lily** is an AI-powered social media marketing agent that helps you manage your entire marketing workflow — from content creation to publishing and analytics — through a simple chat interface.

Instead of juggling multiple tools, just **tell Lily what you want**, and it executes using intelligent Agent (based on Hybrid - Agent/Pipeline Architecture).

---

## ✨ Key Features

* 🤖 Chat-based marketing automation 
* 🧠 5 Prebuilt intelligent pipelines
* 📊 Social media analytics & insights
* 🔍 Influencer & content discovery
* ✍️ Multi-format content generation
* 🚀 Direct publishing to platforms
* 📊 Future Content Scheduling

## ⚙️ Development Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
```

---

### 2. Open the Project

* Open **Android Studio**
* Click **Open**
* Navigate to:

  ```
  MobileApp/MarketingAgent
  ```
* Wait for Gradle sync

---

### 3. Configure API

Go to:

```
app/src/main/java/com/mota/marketingagent/data/ApiConfig.java
```

Update:

```java
GATEWAY_TOKEN = "YOUR_GATEWAY_TOKEN";
```

---

### 4. Run the App

* Connect Android device OR start emulator
* Click ▶️ Run in Android Studio

OR

```bash
./gradlew assembleDebug
```
